# Trading Skill Pack

Place trading strategy notes, risk rules, screening preferences, and portfolio-management playbooks in this folder as Markdown files.

Every analysis run loads these files and gives them to the LLM layer as reference material. Keep each skill concise and practical:

- Market regime filters
- Entry and exit rules
- Position sizing rules
- Risk limits
- Sector or small-cap screening rules
- Red flags to avoid

The simulator is still paper trading only. Skills should improve analysis and simulated decision quality, not trigger real-money execution.
